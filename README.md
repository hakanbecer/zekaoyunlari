# 🎮 Akıl ve Zekâ Oyunları Platformu

Milli Eğitim Bakanlığı (MEB) müfredatı, Bilişim Teknolojileri ve Akıl & Zekâ Oyunları atölyelerine uygun olarak geliştirilmiş **16 interaktif dijital zekâ oyunu** koleksiyonu ve web portalı.

Bu proje, öğrencilerin problem çözme, stratejik planlama, uzamsal algı, mantıksal çıkarım ve sözel akıl yürütme becerilerini geliştirmeyi amaçlar.

---

## 🌟 Öne Çıkan Özellikler

- **16 İnteraktif Oyun:** Strateji, mantık, matematik, uzamsal ve sözel alanlarda zengin oyun yelpazesi.
- **Tek Sayfa Portalı (Hub):** Canlı arama, kategori filtreleme, rastgele oyun seçici ve sayfadan ayrılmadan gömülü oynama imkânı.
- **Her Cihazla Uyumlu:** Akıllı tahtalar, tabletler, dokunmatik ekranlar ve masaüstü bilgisayarlarla %100 uyumlu.
- **Bağımsız & Hafif:** Harici bir veritabanı veya sunucu gerektirmez; toplam boyutu yalnızca ~1 MB'tır.
- **GitHub Pages Hazır:** GitHub'a yükleyip tek tıkla ücretsiz web sitesi olarak yayınlanabilir.
- **Çevrim Dışı (Offline) Desteği:** İnternet bağlantısı olmadan da USB bellek veya yerel diskten doğrudan çalışır.

## 💻 Yerel Olarak Çalıştırma (Offline)

1. Bu klasörü bilgisayarınıza indirin veya açın.
2. Klasörün kök dizinindeki **`index.html`** dosyasına çift tıklayarak herhangi bir modern tarayıcıda (Chrome, Edge, Firefox, Safari) açın.
3. Herhangi bir kurulum veya yerel web sunucusu gerektirmez!

## 🚀 GitHub ve GitHub Pages'e Yükleme Rehberi

Bu projeyi GitHub'da barındırmak ve ücretsiz bir web sitesi olarak yayınlamak için şu adımları izleyebilirsiniz:

### 1. Git Başlatma ve Commit Oluşturma
Terminal veya PowerShell'i bu klasör içinde açıp sırasıyla çalıştırın:

```bash
git init
git add .
git commit -m "feat: Akil ve zeka oyunlari web portali ve 16 oyun"
```

### 2. GitHub Deposu Oluşturma ve Gönderme
1. [GitHub](https://github.com)'a giriş yapın ve yeni bir genel (Public) repository oluşturun (örn: `akil-ve-zeka-oyunlari`).
2. Terminalinizde deponuzu bağlayıp dosyaları yükleyin:

```bash
git branch -M main
git remote add origin https://github.com/KULLANICI_ADINIZ/REPO_ADINIZ.git
git push -u origin main
```

### 3. GitHub Pages'i Aktif Etme
1. GitHub deponuzda **Settings** (Ayarlar) sekmesine gidin.
2. Sol menüden **Pages** seçeneğine tıklayın.
3. **Build and deployment** başlığı altında:
   - **Source:** `Deploy from a branch`
   - **Branch:** `main` / `root (/)` seçin.
4. **Save** butonuna tıklayın.
5. 1-2 dakika içinde siteniz `https://KULLANICI_ADINIZ.github.io/REPO_ADINIZ/` adresinde canlıya geçecektir!

## 🏫 Sınıf İçi ve Akıllı Tahta Kullanımı

- Sınıflardaki etkileşimli tahtalarda tarayıcı üzerinden açıp **F11** tuşuna basarak veya oyun içi **Tam Ekran** butonunu kullanarak tam ekran yapabilirsiniz.
- Dokunmatik ekranlarda doğrudan parmak hareketleriyle taş sürme, döndürme ve seçim işlemleri yapılabilir.
- Her oyunun sol alt köşesinde bulunan **"🏠 Ana Sayfa"** butonu sayesinde öğrenciler tek tıkla ana oyun menüsüne dönebilir.
